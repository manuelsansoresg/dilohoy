Esta carpeta se deja intencionalmente sin dependencias obligatorias.

El rediseño corregido carga las imágenes de marca directamente desde el sitio
actual de DiloHoy para que al probarlo en local NO aparezcan errores 404 ni
sea necesario crear enlaces simbólicos, copiar imágenes manualmente o cambiar
rutas.

Cuando quieras hacerlo 100% local/offline, puedes colocar aquí las imágenes y
cambiar las URLs del index.php. Para el uso actual no es necesario.
